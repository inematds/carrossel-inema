Em resumo

O carrossel-inema é uma skill (um conjunto de instruções e scripts) para o Claude Code que faz carrosséis de Instagram e TikTok; as mesmas imagens servem para o Facebook. Serve para quem quer postar com frequência sem abrir programa de design. Você dá o tema; ele entrega a capa, de 5 a 10 slides com uma ideia cada, o slide final com "comenta PALAVRA" e 3 stories, todos no tamanho certo. Antes de mostrar, ele confere se algum texto ficou cortado ou pequeno demais. Para usar, precisa de um computador Linux ou Mac (no Windows, pelo WSL, o Linux que roda dentro do Windows) com Node.js, Python e o Claude Code; para a capa com arte, o Codex logado na sua conta do ChatGPT. Os textos saem em português por padrão; o idioma se troca no PERFIL.md.

O que é

Um carrossel inteiro sem abrir o Canva

Roteiro, arte, slides, stories e checagem no mesmo lugar. Você só aprova.

🖼️ Capa que segura o dedo

O Codex desenha a capa com o título escrito dentro da imagem. A checagem pede número, o assunto pelo nome e no máximo 4 linhas, e mede se a foto saiu amarelada.

🧱 Slides limpos, um por ideia

Número grande, título, 2 ou 3 frases e o trecho-chave em negrito, no tamanho do feed (1080×1350). Se o texto não cabe, a letra encolhe e o relatório avisa.

✅ Nada vai ao ar sem você

Ele mostra todas as imagens e a legenda e espera o seu "aprovado". Cada correção sua vira uma regra no PERFIL.md e não precisa ser repetida.

Como funciona

As etapas, do tema ao post

O banner acima mostra as 6 etapas principais; aqui está o caminho completo, com dois portões: a checagem automática e a sua aprovação. Os passos com você acontecem na conversa com o Claude; o resto é script. A "palavra" é o que você pede para as pessoas comentarem (ex.: GUIA); quem comenta recebe de você o link de um material grátis seu (uma página, um PDF). A skill escreve o convite; mandar o link para quem comentou fica com você ou com a sua ferramenta de mensagens.

Tema→ Palavra + guia grátis→ Roteiro (roteiro.json)→ Capa pelo Codex→ Montagem das imagens→ Checagem→ Sua aprovação→ Postagem no Metricool
Pré-requisitos

O que precisa estar na máquina

Sem chave de API paga. A arte sai pela sua assinatura do ChatGPT.

Node.js 18+ (com npm) e Python 3

Node.js é o programa que monta as imagens; o npm instala a peça que ele usa (versão 18 ou mais nova: no Ubuntu, sudo snap install node --classic; no Mac, brew install node; ou nodejs.org). O Python faz a checagem e chama o Codex; o Pillow, um complemento do Python, mede se a capa saiu amarelada. Confira as versões e instale o Pillow com o bloco do seu sistema. O ffmpeg é opcional (ajusta o tamanho da capa); sem ele, o aviso do autoteste pode ser ignorado.

node -v && npm -v && python3 --version

Ubuntu

sudo apt install python3-pil ffmpeg

Mac

python3 -m pip install pillow
brew install ffmpeg

Um Chromium

Chromium é um navegador; o sistema o usa sem janela, por trás, para desenhar cada imagem. Se você não tem, o primeiro comando instala (se ele perguntar "Ok to proceed?", responda y). No Ubuntu, o segundo instala as bibliotecas que o navegador usa. No Mac com o Google Chrome instalado, não precisa de nada: o sistema o encontra sozinho.

Ubuntu

npx playwright install chromium
sudo npx playwright install-deps chromium

Mac sem Google Chrome

npx playwright install chromium

Claude Code + Codex

Claude Code roda a skill (instalação em claude.com/claude-code). O Codex (programa de terminal da OpenAI: npm i -g @openai/codex e depois codex login) desenha a capa pela sua conta do ChatGPT. É opcional: sem ele, sai uma capa só com letras.

claude --version && codex --version

Só para postar: gh + Metricool (Linux ou WSL)

A postagem automática roda no Linux ou no WSL; no Mac, poste as imagens à mão. O Metricool (agendador de posts) precisa das imagens num link público: o script as coloca num repositório público seu no GitHub (uma pasta de arquivos na internet), pelo gh, o programa do GitHub para o terminal. Instale, entre na sua conta e crie o repositório com os comandos abaixo. O Metricool tem de estar ligado ao Claude Code como conector (MCP: o jeito de o Claude usar um serviço de fora). O último comando abaixo cria o conector com o nome metricool; depois, no Claude Code, digite /mcp, escolha metricool e entre com a sua conta do Metricool. Sem isso, baixe as imagens e poste pelo celular.

sudo apt install gh
gh auth login
gh repo create carrossel-imagens --public --add-readme
claude mcp add --transport http --scope user metricool https://ai.metricool.com/mcp
Guia de uso · passo a passo

Do zero ao primeiro carrossel

Comandos copiáveis, na ordem.

1

Instale e rode o autoteste

Baixa o projeto, instala a única dependência e gera um carrossel de teste. Tem que terminar em SELFTEST PASS ("autoteste passou").

git clone https://github.com/inematds/carrossel-inema ~/projetos/carrossel-inema
cd ~/projetos/carrossel-inema
bash setup.sh
2

Ligue a skill no Claude Code e troque a marca

O comando cria a pasta de skills (se não existir) e um atalho para o projeto. Feche e abra o Claude Code de novo para ele enxergar a skill. O PERFIL.md vem com a marca do INEMA (perfil, nome, fecho e hashtags): troque tudo pela sua antes do primeiro carrossel, ou peça ao Claude: "preencha o PERFIL.md comigo". O SKILL.md (o passo a passo que o Claude segue) também cita a conta do INEMA na postagem; vale o que estiver no seu PERFIL.md.

mkdir -p ~/.claude/skills
ln -s ~/projetos/carrossel-inema ~/.claude/skills/carrossel-inema
3

Peça o carrossel

No Claude Code, diga o tema (ou pergunte "qual deve ser o próximo carrossel?"). Ele propõe 3 títulos de capa e mostra o roteiro antes de gerar qualquer imagem. A skill cria sozinha a pasta do trabalho em ~/projetos/output/carrossel-inema/<data>-<tema>/, com o roteiro.json (o texto de cada slide), a legenda.txt (o texto que vai junto do post) e a pasta slides/ com as imagens.

faz um carrossel sobre agentes de IA para pequenas empresas
4

Capa, imagens e checagem (a skill faz)

A skill roda estes comandos por você. Eles ficam aqui para quem quiser rodar à mão, de dentro da pasta do projeto; PASTA=… guarda o caminho da pasta do passo 3 num apelido, e $PASTA usa esse apelido. O Codex desenha a capa com o título dentro; a skill pede para você conferir o texto da arte e só segue depois do seu OK.

cd ~/projetos/carrossel-inema
PASTA=~/projetos/output/carrossel-inema/2026-11-01-agentes
python3 scripts/capa.py $PASTA/roteiro.json --estilo 3d --cena "braços robóticos organizando papéis"
node scripts/render.mjs $PASTA/roteiro.json $PASTA/slides
python3 scripts/checa.py $PASTA/slides $PASTA/roteiro.json
5

Aprove

Ela mostra os quadros lado a lado e a legenda. Você aprova ou pede ajuste; cada ajuste vira uma regra no PERFIL.md. As imagens prontas ficam em $PASTA/slides/ e já podem ser postadas à mão.

aprovado

Pode responder no seu idioma: a skill entende.

6

Poste pelo Metricool (opcional, ainda não testado)

Primeiro uso: o mais simples é baixar as imagens de $PASTA/slides/ e postar pelo celular. A postagem automática ainda não foi testada e vem configurada para a conta do INEMA. Para a sua, defina antes (com export, que guarda o valor para os comandos seguintes) o seu repositório público no GitHub, o nome do conector do Metricool e a sua marca no Metricool; o script usa essas três informações nas duas linhas. O padrão é rascunho: nada vai ao ar sem AO_VIVO=1. Por baixo, o script abre o Claude Code sem janela para falar com o Metricool: usa a sua assinatura e pode levar alguns minutos.

export REPO=voce/carrossel-imagens CONECTOR=metricool MARCA=sua.marca
scripts/publicar.sh $PASTA/slides $PASTA/legenda.txt
AO_VIVO=1 scripts/publicar.sh $PASTA/slides $PASTA/legenda.txt
