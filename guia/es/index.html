En resumen

carrossel-inema es una skill (un conjunto de instrucciones y scripts) para Claude Code que crea carruseles de Instagram y TikTok; las mismas imágenes sirven para Facebook. Está pensada para quienes quieren publicar con frecuencia sin abrir un programa de diseño. Le das un tema y te entrega la portada, de 5 a 10 diapositivas con una idea cada una, la diapositiva final con «comenta PALABRA» y 3 stories, todo en el tamaño correcto. Antes de mostrarlo, revisa si algún texto quedó cortado o demasiado pequeño. Para usarla, necesitas un ordenador Linux o Mac (en Windows, mediante WSL, el Linux que funciona dentro de Windows) con Node.js, Python y Claude Code; para la portada ilustrada, necesitas Codex con la sesión iniciada en tu cuenta de ChatGPT. Los textos se generan en portugués de forma predeterminada; el idioma se cambia en PERFIL.md.

Qué es

Un carrusel completo sin abrir Canva

Guion, arte, diapositivas, stories y revisión en un mismo lugar. Solo tienes que aprobar.

🖼️ Una portada que detiene el dedo

Codex diseña la portada con el título escrito dentro de la imagen. La revisión pide un número, el tema escrito y un máximo de 4 líneas, y comprueba si la foto quedó amarillenta.

🧱 Diapositivas limpias, una idea por diapositiva

Número grande, título, 2 o 3 frases y el fragmento clave en negrita, al tamaño del feed (1080×1350). Si el texto no cabe, la letra se reduce y el informe lo indica.

✅ Nada se publica sin ti

Te muestra todas las imágenes y el texto del post, y espera tu «aprobado». Cada corrección tuya se convierte en una regla en PERFIL.md y no tendrás que repetirla.

Cómo funciona

Las etapas, del tema a la publicación

El banner de arriba muestra las 6 etapas principales; aquí está el recorrido completo, con dos controles: la revisión automática y tu aprobación. Los pasos que requieren tu participación ocurren en la conversación con Claude; el resto son scripts. La «palabra» es lo que pides a la gente que comente (p. ej., GUIA); quien la comenta recibe de ti el enlace a un material gratuito tuyo (una página, un PDF). La skill redacta la invitación; enviar el enlace a quien comentó queda a tu cargo o al de tu herramienta de mensajería.

Tema→ Palabra + guía gratuita→ Guion (roteiro.json)→ Portada con Codex→ Montaje de imágenes→ Revisión→ Tu aprobación→ Publicación en Metricool
Requisitos previos

Qué debe estar instalado en el equipo

Sin claves de API de pago. El arte se genera con tu suscripción de ChatGPT.

Node.js 18+ (con npm) y Python 3

Node.js es el programa que monta las imágenes; npm instala el componente que utiliza (versión 18 o posterior: en Ubuntu, sudo snap install node --classic; en Mac, brew install node; o nodejs.org). Python realiza la revisión y llama a Codex; Pillow, un complemento de Python, comprueba si la portada quedó amarillenta. Comprueba las versiones e instala Pillow con el bloque de tu sistema. Se recomienda ffmpeg: ajusta la portada y monta la hoja con los cuadros uno al lado del otro para que la apruebes.

node -v && npm -v && python3 --version

Ubuntu

sudo apt install python3-pil ffmpeg

Mac

python3 -m pip install pillow
brew install ffmpeg

Chromium

Chromium es un navegador; el sistema lo usa sin ventana, en segundo plano, para dibujar cada imagen. Si no lo tienes, el primer comando lo instala (si pregunta «Ok to proceed?», responde y). En Ubuntu, el segundo instala las bibliotecas que usa el navegador. En Mac con Google Chrome instalado, no hace falta nada: el sistema lo encuentra automáticamente.

Ubuntu

npx playwright install chromium
sudo npx playwright install-deps chromium

Mac sin Google Chrome

npx playwright install chromium

Claude Code + Codex

Claude Code ejecuta la skill (instalación en claude.com/claude-code). Codex (el programa de terminal de OpenAI: npm i -g @openai/codex y luego codex login) diseña la portada con tu cuenta de ChatGPT. Es opcional: sin él, se genera una portada solo con texto.

claude --version && codex --version

Solo para publicar: gh + Metricool (Linux o WSL)

La publicación automática funciona en Linux o WSL; en Mac, publica las imágenes manualmente. Metricool (programador de publicaciones) necesita las imágenes en un enlace público: el script las coloca en un repositorio público tuyo en GitHub (una carpeta de archivos en internet) mediante gh, el programa de GitHub para la terminal. Instálalo, inicia sesión en tu cuenta y crea el repositorio con los comandos de abajo. Metricool debe estar conectado a Claude Code como conector (MCP: la forma de que Claude use un servicio externo). El último comando crea el conector con el nombre metricool; después, en Claude Code, escribe /mcp, elige metricool e inicia sesión en tu cuenta de Metricool. Si no, descarga las imágenes y publícalas desde el móvil.

sudo apt install gh
gh auth login
gh repo create carrossel-imagens --public --add-readme
claude mcp add --transport http --scope user metricool https://ai.metricool.com/mcp
Guía de uso · paso a paso

De cero al primer carrusel

Comandos que puedes copiar, en orden.

1

Instala y ejecuta la autoprueba

Descarga el proyecto, instala la única dependencia y genera un carrusel de prueba. Debe terminar con SELFTEST PASS («autoprueba superada»).

git clone https://github.com/inematds/carrossel-inema ~/projetos/carrossel-inema
cd ~/projetos/carrossel-inema
bash setup.sh
2

Activa la skill en Claude Code y cambia la marca

El comando crea la carpeta de skills (si no existe) y un acceso directo al proyecto. Cierra y vuelve a abrir Claude Code para que detecte la skill. PERFIL.md viene con la marca de INEMA (perfil, nombre, cierre y hashtags): cámbialo todo por lo tuyo antes del primer carrusel, o pídele a Claude: «completa el PERFIL.md conmigo». SKILL.md (los pasos que sigue Claude) también menciona la cuenta de INEMA al publicar; prevalece lo que figure en tu PERFIL.md.

mkdir -p ~/.claude/skills
ln -s ~/projetos/carrossel-inema ~/.claude/skills/carrossel-inema
3

Pide el carrusel

En Claude Code, indica el tema (o pregunta «¿cuál debería ser el próximo carrusel?»). Propone 3 títulos para la portada y muestra el guion antes de generar cualquier imagen. La skill crea automáticamente la carpeta del trabajo en ~/projetos/output/carrossel-inema/<fecha>-<tema>/, con roteiro.json (el texto de cada diapositiva), legenda.txt (el texto que acompaña la publicación) y la carpeta slides/ con las imágenes.

crea un carrusel sobre agentes de IA para pequeñas empresas
4

Portada, imágenes y revisión (la skill se encarga)

La skill ejecuta estos comandos por ti. Aquí están para quien quiera ejecutarlos manualmente, desde la carpeta del proyecto; PASTA=… guarda la ruta de la carpeta del paso 3 con un alias (cambia el nombre del ejemplo por el de tu carpeta, que puedes ver con ls), y $PASTA usa ese alias. Codex diseña la portada con el título incluido; la skill te pide que revises el texto del arte y solo continúa cuando le das el visto bueno.

ls ~/projetos/output/carrossel-inema/
cd ~/projetos/carrossel-inema
PASTA=~/projetos/output/carrossel-inema/2026-11-01-agentes
python3 scripts/capa.py $PASTA/roteiro.json --estilo 3d --cena "brazos robóticos organizando papeles"
node scripts/render.mjs $PASTA/roteiro.json $PASTA/slides
python3 scripts/checa.py $PASTA/slides $PASTA/roteiro.json
5

Aprueba

Te muestra los cuadros uno al lado del otro y el texto del post. Apruebas o pides un ajuste; cada ajuste se convierte en una regla en PERFIL.md. Las imágenes listas quedan en $PASTA/slides/ y ya puedes publicarlas manualmente.

aprobado

Puedes responder en tu idioma: la skill te entiende.

6

Publica con Metricool (opcional, aún no probado)

La primera vez, lo más sencillo es descargar las imágenes de $PASTA/slides/ y publicarlas desde el móvil. La publicación automática aún no se ha probado y viene configurada para la cuenta de INEMA. Para usar la tuya, define primero (con export, que guarda el valor para los comandos siguientes) tu repositorio público de GitHub, el nombre del conector de Metricool y tu marca en Metricool; el script usa estos tres datos en las dos líneas. Cambia tu por tu usuario de GitHub y tu.marca por el nombre de la marca que aparece en el selector de marcas de Metricool. De forma predeterminada se crea un borrador: nada se publica sin AO_VIVO=1. Por debajo, el script abre Claude Code sin ventana para comunicarse con Metricool: usa tu suscripción y puede tardar unos minutos.

export REPO=tu/carrossel-imagens CONECTOR=metricool MARCA=tu.marca
scripts/publicar.sh $PASTA/slides $PASTA/legenda.txt
AO_VIVO=1 scripts/publicar.sh $PASTA/slides $PASTA/legenda.txt
